# Ganjuko Forest Kit 1

Deep-woods pieces for routes and forest maps: denser and moodier than the
commons trees, with campsite and landmark props. The combined sheet
(`sheets/GanjukoForest_B.png`) contains this kit **plus the shared commons**
(round tree, pine, rocks, grass tuft, wildflowers).

- **Sheet:** `sheets/GanjukoForest_B.png` (768x768, B slot)
- **Fragment:** `tileset-fragment-forest.json`
- **Layout map:** `sheetmap-forest.json`
- **Catalog:** `../../library.json` (`biome: "forest"` / `"commons"`)

## Contents

- **trees** — a 3x3 dense tree cluster (instant forest edge), old oak,
  birch, owl-hollow tree, young pine, plus pure-canopy pieces
  (`canopy_top`, `canopy_arch`) that are all-`star`: paint them over paths
  to make canopy tunnels the player walks *under*.
- **undergrowth** — ferns, mushroom ring and cluster, berry bush, leaf
  pile, sapling. Most are `bush`-flag walkable ground cover (feet hidden),
  so forest floors feel soft instead of tiled.
- **woodland props** — fallen and hollow logs, stumps, wood pile, log bench,
  vine pole, bee hive and spider web (star overlays), birdhouse pole.
- **landmarks** — a mossy forest shrine (front row is a **counter** for
  offering-style interactions) and horizontal/vertical plank bridges
  (all-`pass`: paint over streams and ravines).
- **campsite** — campfire, a 2x2 campfire site with log seats, canvas tent.
- **paths** — stepping stones and a dirt patch (flat, walkable).
